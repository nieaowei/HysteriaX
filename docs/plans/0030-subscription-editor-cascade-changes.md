# 0030 订阅编辑器级联变更

日期：2026-10-20。状态：已实施。

1. 使用 Schema 引用元数据及 Mihomo 规则语法识别依赖，避免替换同名域名、密码和未知字段。
2. 对对象标签重命名同步更新引用、默认目标及动态注入组；加入重名检查，并把对象与引用写入同一撤销事务。
3. 删除被引用对象时计算依赖闭包：删除依赖规则，处理组成员和默认引用，必要时删除后续依赖对象；逻辑规则按整条规则删除。
4. 在列表及映射编辑入口呈现级联删除预览，列出原始路径及完整差异；取消不写入，确认检查草稿仍与预览基线一致，整次删除一次撤销。
5. 验证两种格式、全部已索引引用类别、多标签规则集、端点、平台覆盖、注入规则、重名、未知字段、旧值保留、预览取消与撤销重做，更新完整优化报告。

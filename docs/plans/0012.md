# 移除授权组成员和节点变更预览

日期：2026-10-29（Asia/Shanghai）
状态：已实施，验证通过

## 用户要求

授权组成员和节点修改直接执行，不显示保存前操作摘要或强制预览，执行后再显示实际影响摘要。以 10 万用户、1 万节点为设计前提。

## 实施

1. 成员、节点和共用更新接口上的名称编辑直接保存；移除成员影响页、预览按钮、保存前待增减人数摘要及预览失效处理。保留草稿编辑、跨页选择和撤销草稿修改。
2. 更新请求移除 `preview_token`，拒绝旧令牌字段；组预览接口仅接受删除，不再接受更新。创建、删除授权组和用户页修改所属组的预览不在本次范围内。
3. 服务端直接读取授权图并准备 mTLS 身份签发，不持久化隐藏预览。事务内继续校验组版本、锁定受影响资源、重新核对有效权限和身份签发计划，保留幂等回放、审计和批量撤权任务。
4. 执行完成后显示实际新增、撤销授权数量，保留撤权任务的排队、执行、完成和失败状态。版本冲突保留草稿并提示重新打开编辑，避免覆盖其他管理员的修改。
5. 同步 OpenAPI、生成的 Swift 请求模型、中英文文案、说明文档和测试；移除旧节点预览测试及只用于预览的成员重新合并逻辑。
6. 不改变数据库结构及既有授权数据，无需数据迁移工具。服务端和客户端需要配套更新；已有更新预览不会再消费，继续按原有过期清理机制回收。本次不部署生产。

## 验证

- 使用本地独立可丢弃 PostgreSQL 18 容器，未访问生产数据库或节点；测试后已删除容器。
- 授权组回归 29 项通过：直接增减成员及节点、返回实际数量、更新不生成隐藏预览、拒绝旧预览协议、版本冲突、事务回滚、幂等回放、并发及批量撤权。
- mTLS 授权流程 12 项通过，包含新增的直接更新签发及撤权归档测试。
- macOS 界面 2 项通过：大组成员跨页选择后直接保存、移除节点后直接保存；两者均无预览按钮，完成后显示实际授权变化。测试报告：`apps/macos/.build/authorization-ui-1793212390.xcresult`。
- 客户端检查通过，包括无预览请求、无预览令牌、5000 成员和 20000 连接处理、跨页选择及定向撤销。
- 中英文 1974 条资源覆盖及本地化运行时检查通过；OpenAPI 生成一致性、Rust 格式、Python 脚本语法及 `git diff --check` 通过。

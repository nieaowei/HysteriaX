# 0023 节点页服务端分页

日期：2026-10-09

## 目标

为节点页增加分页、总数显示和全目录搜索/排序，保留中文状态搜索、详情、配置、节点任务、新建/删除及跨页跳转流程。

## 实施步骤（已完成）

1. 新增 `GET /api/v1/nodes/page`，返回 `{ items, total, page, page_size }`。
   - 默认第 1 页、每页 50 条，支持 1–200 条；非法参数返回 400，越界页码返回最后一页，空结果返回第 1 页。
   - 搜索名称、SSH 主机、节点 ID 和原始状态；客户端将匹配的中英文状态标签转换为原始状态代码，后端以绑定数组加入搜索。
   - 名称、SSH 主机、状态及创建时间排序使用白名单，名称/ID 为稳定后续排序字段。
   - 总数和当前页基础行在同一个只读、可重复读事务中查询，SQL LIMIT/OFFSET 限定页记录。
   - 释放事务连接后，复用现有节点摘要装配流程读取套餐、实时采样、DNS 绑定、SSH 和配置预览。避免单连接池被事务占用导致关联读取死锁；实时关联数据维持原详情接口语义。
2. 更新 OpenAPI、生成器、Swift DTO/端点及按需读取节点页的方法。
   - 原完整节点目录接口保持不变，继续供用户授权、DNS、任务、概览和离线快照使用。
   - 新增 `0015_nodes_pagination.sql` 的名称/ID 联合索引。
3. 节点页增加上一页/下一页、25/50/100 条选项、总数/页码、加载提示、错误显示和重试。
   - 搜索、排序、每页条数及语言变化后回到第一页；手动翻页清除旧选择。
   - 页请求检查取消与请求标识；服务切换清空页缓存、选择及节点提交状态。
   - 外部请求直接按 ID 选择完整目录中的节点，详情可打开不在当前页或筛选结果中的节点。
   - 详情优先采用修订号更新的摘要；原配置、任务、SSH 测试、部署/同步、回滚和删除入口保持可用。
   - 离线时对完整缓存目录分页并显示离线标识。
4. 将状态标签整理为共享 NodeDisplayText，补充中英文、节点任务、网络及 UI 协议夹具回归。
5. 本地构建 amd64 镜像、上传校验后部署 Server1，验证公网分页及现有接口。

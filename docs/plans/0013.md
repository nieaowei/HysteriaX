# 移除全部授权预览

日期：2026-10-29（Asia/Shanghai）
状态：已部署生产（2026-10-29）

## 用户要求

在移除成员和节点变更预览之后，继续移除全部授权预览，包括创建授权组、删除授权组和用户所属组调整，并清理预览数据库表。所有操作直接执行，执行后显示实际影响摘要。按 10 万用户、1 万节点的规模维护。

## 实施

1. 删除三个授权预览路由、请求/响应模型、令牌字段及服务端预览生成、摘要存储、校验、消费和过期回收代码。所有授权写请求拒绝旧 `preview_token` 字段，不保留旧协议兼容。
2. 创建、修改、删除授权组和用户所属组调整统一直接提交。服务端在写事务之前准备连接密码和 mTLS 签名，在事务中检查修订、锁定相关授权资源、重新计算实际权限、核对身份计划并原子记录分配、撤权、审计及幂等回执。
3. macOS 创建和用户所属组编辑直接保存；点击删除直接执行后显示结果。删除预览页、权限明细和预签发统计组件，执行后显示实际授权增减和撤权任务状态。同步真实 Xcode 工程文件与生成模型。
4. 新增独立数据库迁移 `0003_remove_authorization_previews.sql`，删除 `authorization_group_previews` 全表数据、索引和约束，保留授权组、成员、节点、凭据及撤权需求。保持已发布 0001/0002 校验和不变，新库按完整迁移链初始化后同样没有预览表。
5. 部署和测试环境使用新镜像或二进制的 `--migrate-only` 执行该迁移；执行前停止所有 API。需要配套更新服务端与客户端。本次仅在本地隔离数据库验证，未部署或修改生产数据库。
6. 删除过时预览测试并改写为直接提交、旧接口拒绝、过期版本、迁移保留业务数据、并发、事务回滚、幂等回放和签名准备验证。同步 HTTP/界面测试夹具、共享授权夹具、管理契约和说明文档，清理未使用的预览翻译。
7. 订阅模板、节点 YAML 等其他业务的预览不在授权流程范围内，保留。

# 0007 节点列表流量进度条

日期：2026-10-04

## 目标

节点列表的套餐流量采用与用户列表一致的细条渐变样式。

## 实施步骤（已完成）

1. 将用户列表的流量展示提取为共享 `QuotaProgressView`，并加入 Xcode 构建源文件。
2. 节点列表使用同一组件展示已用量、额度和渐变进度条：正常为蓝青渐变，达到 90% 为橙红渐变，超额填充限制为满格。
3. 不限额度使用无限图标；未知用量显示「—」和空底槽，避免将尚未采集误显示为零用量。
4. 保留节点套餐的重置时间与告警信息，设置与用户列表相同的最小列宽。

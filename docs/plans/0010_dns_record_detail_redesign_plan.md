# DNS 记录详情区重新设计

日期：2026-10-07
状态：已实施

## 实施内容

1. 提取 `DNSRecordDetailView`，加入 Xcode 编译目标。
2. 固定标题和常用操作区：域名、类型、写入状态，编辑、检查解析和绑定节点；更多菜单提供任务、审计和删除入口。
3. 将详情分成记录信息、解析与节点两组，使用自适应网格显示目标、TTL、代理模式、来源、区域、连接、检查时间和节点绑定。
4. 明确展示待执行变更、失败重试、只读和代理模式提示；折叠展示解析检查结果和记录标识。
5. 沿用原有操作回调、删除确认和权限限制，以及稳定的 `VSplitView` 上下分区。

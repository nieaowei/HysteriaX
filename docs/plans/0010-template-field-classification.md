# 0010 订阅模板字段按用途分类

## 目标

将主要按数据类型和英文字段名生成的分区改为按用途分组，保留已有原生控件、配置路径、继承和移除语义。

## 实施步骤（已完成）

1. 将导航与分区元信息抽到 `Models/TemplateFieldLayout.swift`，统一管理字段归属、中文标题和各导航页的展示顺序。
2. 展开 DNS、路由、日志、持久化、时间同步、TUN、嗅探、证书等已验证的固定结构对象；保留整体对象状态入口，未验证对象继续使用原有保护。
3. 将简单字段按用途合并：DNS 解析和缓存、入站端口和局域网访问、路由默认值和出口接口、控制 API 和 Web 界面等分别呈现。复杂集合保持独立分区，并使用可读标题。
4. 将嗅探和进程发现归入分流规则，将时间同步和控制接口相关选项归入基础配置，将入站协议和端口转发归入入站导航。
5. 补充中英文本地化，并为实际 sing-box、Mihomo 字段目录增加分类覆盖检查，接入现有客户端验证脚本。

## 验证

- SwiftPM 和 Xcode Debug 构建通过。
- `scripts/verify-subscription-client.sh` 通过，包括现有配置覆盖、撤销重做、会话隔离回归及新增字段目录分类检查。
- 分类检查覆盖 sing-box 的 79 个展示路径和 Mihomo 的 173 个展示路径，当前已支持字段均具有明确分区。
- 工程文件、两种语言资源的格式检查及 `git diff --check` 通过。
- 未运行完整窗口 UI 回归；字段分组本身通过实际目录覆盖检查验证。

# 0008 节点列表与详情布局优化

## 目标

减少节点列表的横向信息碎片，统一节点、用户、任务和凭据页面的上下详情布局。

## 实施步骤（已完成）

1. 将列表整合为名称、SSH 地址、状态、配置、套餐、采样六列，设置列宽；保留目标与已部署版本、有效期、统计缺口和待撤权提示。
2. 在下方详情固定节点名称、状态、关键指标及操作栏；将配置和次要操作归入菜单，保留原有动作与删除确认流程。
3. 连接信息与套餐流量宽屏并排、窄屏上下排列，采样待办单独展示；分配用户、指纹和节点记录按需展开。
4. 读取选中节点的公开连接详情；按节点、配置修订版、服务地址和连接状态更新请求，忽略取消或已切换上下文的响应，并提供失败重试入口。

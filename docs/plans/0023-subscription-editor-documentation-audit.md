# 0023 订阅编辑器逐项文档核查与优化

已实施，2026-10-20。完整结论见 [优化报告](../subscription-editor-optimization-report.md)。

## 范围与实施

1. 核验 sing-box v1.14.2 固定提交、上游 Schema 和完整英文配置文档树的 SHA-256；遍历 121 页，生成每一页、每个字段/动作标题的对应结果及可解析的 Schema 指针。
2. 抓取官方中文在线配置导航全部 125 页；记录页面哈希，对比所有字段标题，区分新页面、历史配置、翻译差异、产品限制和固定版本差异。
3. 修正合并字段标题提取；为合并标题生成共同锚点，对重复标题回退整页；排除中文文件重复索引，并提供生成结果校验模式。
4. 补齐 UDP over TCP 文档定位及默认版本 2 的只读预览；补齐有文字依据的 DNS 超时、远程规则集更新周期、缓存路径和 WireGuard MTU 默认预览。
5. 补齐 TUN MAC 过滤依赖、OpenVPN 静态密钥/TLS 模式、控制信道包装类型、推送路由开关、Cloudflared 数据报协议、USB/IP 拨号字段及通用系统 TLS 引擎的条件显示。
6. 列出因当前条件隐藏而保留的已有字段名，避免用户误以为数据丢失；不展示这些字段的凭据值。修正 OpenConnect 保活默认值被通用拨号默认值覆盖的问题。
7. 减少文档元数据在表单渲染中不必要的 Schema 展开；保留原有字段类型、分组、源码编辑、未知值及撤销重做语义。
8. 执行模型、原生 SwiftUI 离屏交互、集合、双语资源、1,046 项校验器兼容性回归和 macOS Debug 构建；保存逐项附录、在线差异清单和验证记录。

## 验收边界

- 全文档覆盖是文档/Schema 对应核查，不代表每一种运行时组合或每个平台都通过实机联网测试。
- 在线新增协议不越过固定版本验证基线；手工出站仍遵循现有产品限制。
- 本次为客户端与审计工具改进，不涉及服务部署。

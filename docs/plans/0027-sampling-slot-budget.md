# 采样窗口预算修复

日期：2026-11-06。状态：已于 21:50:06 部署；稳定窗口 375/375 完成，启动清零交接仍有计量不确定缺口，整体性能尚未验收。

## 生产依据

0026 的生产固定观察及延长复核显示，同节点三类采样共享排他节点租约，周期创建及时，但任务经常到第 40–57 秒才进入运行；一分钟截止后出现真实采样失败。失败流量批次未完成捕获，不是已证实的续租失败。此前顺序窗口未证明取消扫描隔离改动导致该现象；本次单独修复采样路径，不混入 jobs 隔离或空轮询调整。

## 修复范围

按 10 万用户、1 万节点假设保持有界领取和资源级并发，不创建全局采样锁或逐节点进程缓存。保持节点互斥、owner/generation/work/epoch、未知远程操作屏障、一分钟准入截止、清零请求单次发送和已捕获批次的过期后恢复。

1. 多资源领取采用有序批量加锁；未知远程操作在加锁后的独立新语句中查询，防止等待期间提交的 intent 被旧快照漏掉。原子领取全部资源，缺任一资源则回滚候选。
2. 多租约校验合并为一次有序加锁，全部锁获得后再按数据库时间检查最早过期时间，保留每个请求身份，不去重混合代际；业务来源在后续语句中重新核验。
3. 领取元数据一次读取；设置 running 时重新检查 slot，过期候选回滚租约，已捕获流量保留原恢复例外。
4. 流量清零捕获与只读在线/ACME 观测分开推进，辅助观测不再串行挡住清零准入；清零响应先持久化、再验证实例并计量的规则保持。
5. 已捕获计量每次只处理一个有界页（最多 500 用户），未完成时按已有 billing_deferred 机制让出租约，再接续处理，防止大节点长时间独占租约。
6. 过期与失去工作身份分别报错，补充领取、收集和确认阶段耗时，便于生产量化剩余等待。

## 验证要求

先补确定性真实 PG 并发回归：缺资源不得部分领取、未知 intent 不得绕过、身份/代际/epoch/blocked/过期拒绝、等待后过期拒绝、过期候选不进入 running、已捕获过期工作仍可接管。使用本地 SSH 夹具证明慢辅助观测不能阻止窗口内清零，失败观测不能丢弃已捕获计量；保留已有响应丢失、进程接管、拒绝重复清零和计量一次性回归。

同输入受控对照记录事务/SQL 往返、领取与节点租约持有时间、完成量、采样失败及连接等待；不同夹具结果不拼接归因，不以回环端口拒绝连接代替远端采集成功验证。产品变动完成后运行必要回归与项目检查，保存测试输入及原始记录；不把尚未部署的本地结果称作生产修复完成。

## 实施与专项验证

已实现上述六项，无 schema、API 或计量结构变更，不需要数据迁移。ACME 与在线读取各受最多 8 秒的辅助预算约束（较小的配置预算仍生效），与清零捕获共享原受监督节点/工作租约，使用独立 SSH 通道并行推进；使用 join 等待，辅助失败不会取消已发出的清零或丢弃收到的响应。已捕获流量每次只处理一个最多 500 用户的计费页，未完成时沿用 billing_deferred、1 秒后可接续的原状态；页面、计量记录与工作确认仍使用原原子事务和身份屏障。

新增 10 项非忽略回归：7 项租约集合身份/epoch/blocked/过期/锁等待/未知 intent 检查，1 项领取中途过期的整体回滚，2 项 SSH/计量流程。另加强已有清零用例，明确旧 owner 拒绝与 SlotExpired 类型的区别。专项共 11 项通过；新增性能用例默认忽略，另行显式执行。

本地 SSH 夹具实现真实 SSH 认证、exec 与 direct-tcpip HTTP 通道，故意卡住在线人数响应。在该响应仍被阻塞时，断言清零只发送一次、响应已持久化且 17 字节已计量；辅助请求最终返回 HTTP 500 也保持计量成功、在线质量失败和 traffic_status=ok 的区分。501 用户用例验证第一页恰好处理 500 个用户并让出节点，另一类采样可以领取该节点；原 slot 过期后再接管，剩余一页完成，总计 501 条、8517 字节，无重复计费。

为确认回归的辨别力，在隔离源码副本中仅将 sample_node 替换为 HEAD 中的旧函数，其余产品源码和新 SSH 测试保持一致。旧流程稳定在 5.56 秒时失败于“slow online observation blocked destructive capture”，候选通过同一测试。该旧流程未部署，未改动交付工作区；两份冻结二进制和源码摘要均保留。

| 路径 | 逐资源 SQL 事件 | 集合 SQL 事件 | 平均耗时（逐资源→集合） |
| --- | ---: | ---: | ---: |
| 双资源领取 | 90 | 50 | 346→219 ms |
| 双租约校验 | 30 | 20 | 153→121 ms |

## 实施计划与完成情况

1. 在自有 PostgreSQL 18 临时容器中，按原事务边界回放 0001～0074，提取最终 SQL 对象定义和空库初始数据。
2. 新建 `crates/hysteriax-server/migrations/0001_baseline.sql`，删除原 74 个 SQL 文件。后续迁移从 0002 递增。保留相对 schema 引用，`pg_trgm` 及其操作符类仍显式使用 public；仅在基线事务内关闭函数体提前检查，解决函数与后续表定义的依赖顺序。
3. 保留审计总计、随机缓存/事件 epoch、17 个域各 64 个缓存桶。移除历史回填、旧表创建再删除及切换流程，数据库直接得到原 0074 SQL 执行后的结构。凭据字段及约束、模板、引用索引、工作队列和运行时契约仍由既有 Rust 维护初始化按原顺序完成。
4. 测试 fixture 统一使用当前基线，删除按历史版本构建/执行的两个数据库 helper 及 21 个历史 SQL 升级测试；将仍有价值的维护重建、索引及业务数据保留检查调整到当前 schema，保留重复迁移测试。补充初始数据、独立缓存 epoch、旧链及异常迁移历史拒绝检查。
5. 删除原历史链专用验证脚本与 helper，移除容量脚本的旧版协议回退选项。保留当前容量、备份恢复及业务验收入口。完整初始化脚本增加逐项 SHA-384 checksum 校验。
6. 增加 migrations README，更新安装、发布、兼容性、数据库表目录、凭据、mTLS、授权组、订阅及回归文档，修复所有指向本次删除文件的文档链接。

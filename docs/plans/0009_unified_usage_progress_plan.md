# 0009 统一客户端用量进度条

日期：2026-10-04

## 目标

将项目其余用量进度条统一为用户及节点列表采用的细条渐变样式。

## 实施步骤（已完成）

1. 将共享进度条样式开放为 `GradientUsageProgressStyle`，统一维护 4 点高度、胶囊底槽、零进度空槽及填充范围。
2. 管理服务器的 CPU、内存、根目录磁盘进度条使用共享样式。
3. 概览节点额度排行使用共享样式，并将用量比例限制在 0–100%。
4. 所有用量条采用蓝青渐变，达到 90% 时使用橙红渐变。保留已有数值、详情和无数据处理。
5. 读取、连接、保存等无确定比例的加载指示器继续使用系统样式。

## 验证

- 检查全部 `ProgressView(value:)` 调用，均应用共享样式。
- `./script/build_and_run.sh --verify`：编译成功，客户端启动验证通过。
- `git diff --check`：通过。

本次为客户端显示修改，无服务部署。

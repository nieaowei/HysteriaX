# 0024 订阅编辑器默认值专项补齐

已实施，2026-10-20。完整清单见 [默认值核查报告](../audits/0024-default-values.md)。

1. 对照固定 1.14.2 文档的默认值说明及必要的内核源码，建立按对象/协议区分的默认值目录，排除示例值和目标环境动态值。
2. 补齐 OpenVPN TLS、会话模式、MTU、客户端数、认证、算法和重放窗口，OpenConnect、TUIC、ShadowTLS、HTTP/TLS、缓存、API、证书和服务等固定默认值。
3. 为目标平台、服务器协商、编译标签等决定的默认行为提供上下文说明；未知默认的枚举和整数不再假选首项或显示 0。
4. 统一预览、显式设置和列表读取；已有值、null 与空数组优先；浏览不修改草稿，撤销重做保持原有语义。
5. 逐项验证目录字段、类型与枚举范围；回归原生数值输入、枚举选中、列表预览、复杂集合、双语资源与 macOS Debug 构建。

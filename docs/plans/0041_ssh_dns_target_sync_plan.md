# 0041 保存节点 SSH IP 时同步绑定 DNS

日期：2026-10-16。

## 问题与范围

节点 PATCH 原先只更新连接信息，未为绑定 DNS 创建写任务。提交公网 SSH IP 后，绑定域名的同地址族记录应同步，包括再次保存相同 SSH IP 修复旧版本遗留的不一致。

## 实施

1. 节点更新事务内，为绑定的 A/AAAA 同类型记录生成持久化 record-update 操作，固定当前 DNS 凭据版本，并复用 zone 资源锁、节点任务顺序、远端 baseline 比对、恢复幂等及解析检查。
2. 保留域名、类型、TTL、DNS-only 状态和另一地址族记录。非公网 IP、SSH 域名、CNAME 和没有匹配类型记录的绑定不自动更改；没有后台地址发现或自动建另一类型记录。
3. DNS 有未完成写入、非 synced 状态、缺少远端快照或记录歧义时拒绝保存；DNS 入队失败时节点、配置版本、记录意图和任务全部回滚。已经一致的解析不重复写入。
4. PATCH 返回可选 dns_job_ids，macOS 保存成功时显示已排队更新数量；同步 OpenAPI 生成模型、中英文资源和 DNS 文档。

## 验证

回归用例覆盖 IPv4/IPv6、另一地址族保留、同 IP 补同步、字段独立、非公网/域名/CNAME/未绑定分支、过期修订拒绝、未完成 DNS 操作和入队故障事务回滚。Mock Cloudflare 完整写入验证目标内容落地、重复恢复仅一次写入、后续解析检查入队。DNS 测试组 22 项通过。

## 验证结果与发布状态

216 项 Rust 测试全部通过；严格 Clippy、格式和补丁检查通过；OpenAPI lint 与生成一致性检查通过。客户端可解码新返回的 DNS 任务 ID，旧服务缺省字段仍兼容。中英文资源及运行时语言测试通过，macOS 构建和启动验证通过。

API 通过 ssh_dns_sync 能力标识通知客户端显示联动说明。线上只读检查显示现有节点的 IPv4 绑定均已与 SSH IP 一致，本轮没有更改线上节点、DNS 或服务镜像。代码修复尚未部署。

# 0009 — DNS 记录管理与节点域名分配

## 目标与范围

在 HysteriaX 增加独立 DNS 记录管理页，以及节点创建、代理配置和详情中的域名入口，完成域名分配、DNS 写入、证书配置、部署验证和订阅发布闭环。

已确认的产品决定：

- 首期接入 Cloudflare；A、AAAA、CNAME 可创建、编辑、删除，其他类型只读。
- 已有记录允许直接手动编辑，不增加接管步骤。
- 自动分配生成稳定的节点子域名并创建解析；手动分配支持指定域名创建解析或选择已有记录。
- 外部域名/IP 模式继续可用，默认不自动接入 DNS 服务商。
- 创建节点只处理域名和 DNS；ACME 留在代理配置中单独设置，提供「使用已分配域名」按钮。
- 后续 IP 变更由用户明确操作，不做 DDNS、持续公网 IP 探测或自动负载均衡。
- 包含 Rust 服务端、macOS 客户端、接口契约、测试、文档及测试服务器部署。

不包含域名注册、托管迁移、多节点轮询、批量分配、通用 TXT/MX 编辑，以及 ACME TXT 生命周期接管。

## 页面与用户流程

### 独立 DNS 记录页

侧栏入口放在节点之后。页面提供连接/Zone 筛选、搜索、记录表格、记录详情，以及创建、编辑、删除、绑定节点、检查解析、刷新远端、任务和审计入口。

列表显示域名、类型、目标、TTL、绑定节点、操作与解析状态及来源。详情显示待执行修改、失败原因、重试和检查时间。支持缓存展示；详情读取和所有写入需要连接服务。旧服务通过能力标记显示升级提示。

「连接与域名」弹窗使用凭据中心的 Cloudflare DNS 凭据，创建连接、验证读取权限、发现 Zone、启用需要管理的 Zone 并刷新记录。验证读取权限不等于验证写入权限，实际写入任务独立反馈权限不足。

### 节点入口

新建节点的「公开连接」提供外部地址、自动分配、手动指定和已有记录四种模式。

自动域名为 `<前缀>-<节点 ID 后缀>.<Zone>`，默认前缀 `node`。冲突时扩展 ID 后缀，不覆盖远端记录；节点改名不改变域名。自动/指定域名创建 A/AAAA，至少输入一个公网地址。SSH 地址独立，只有显式操作才填入 DNS 目标。

一个节点一个主域名，一个域名只绑定一个节点；可关联同名 A/AAAA 对或单个 CNAME。选择已有记录保留其目标和 TTL。节点使用 DNS only，不接受已知代理链作为直连地址。

代理配置增加「公开连接与域名」，展示目标和已发布地址及 DNS 状态，支持重新分配或解除绑定。域名变更独立保存并重新加载配置。ACME 区域的「使用已分配域名」仅追加、去重域名，保留原条目；不自动修改证书来源或自定义 SNI。

节点详情显示域名与 DNS 跳转。DNS 凭据、版本、引用和更新批次仍由凭据中心管理；任务、重试、事件与审计沿用统一页面。

## 数据与接口

新增迁移 `0009_dns_management.sql`，只增加新结构，不修改已发布迁移：

- `dns_connections`：服务商、凭据 ID/版本、修订和验证状态。
- `dns_zones`：连接、远端 ID、域名、启用状态、修订和同步时间。
- `dns_records`：远端 ID、记录字段、来源、远端快照、目标修改、修订、写入/解析状态和删除时间。
- `dns_bindings`：节点主域名、Zone、记录 ID 和修订。
- `dns_operations`：幂等键、请求摘要、凭据版本、资源、任务、执行意图与完成结果。
- `dns_credential_batch_items`：DNS 连接发布验证批次，保留原节点批次结构。
- jobs 增加资源互斥键及资源类型、ID、名称；nodes 增加已发布连接快照。

所有接口沿用管理员认证和 `/api/v1`：

| 接口 | 用途 |
| --- | --- |
| `/dns/connections`、`/{id}` | 连接创建、查询、改名、删除 |
| `/dns/connections/{id}/verify`、`/refresh` | 验证凭据、发现 Zone |
| `/dns/zones`、`/{id}`、`/{id}/refresh` | 查询、启用、刷新 Zone |
| `/dns/records`、`/{id}`、`/{id}/check` | 记录 CRUD、详情与解析检查 |
| `/nodes/{id}/dns-binding` | 查询、设置、解除节点域名绑定 |

扩展节点创建的 DNS 分配意图，节点详情/摘要的绑定及已发布连接，以及任务的 DNS 资源信息。版本接口增加 `dns_management`。远端操作返回 202 和持久化任务标识；记录写入、绑定和操作请求使用预期修订及幂等键。同键同请求返回原结果，同键不同请求返回 409。

OpenAPI 是契约源，生成 Swift DTO 和操作定义；已有 API 操作定义保持原样，新增字段保持可选兼容。

## 执行、一致性与生命周期

### 任务与恢复

数据库先事务保存节点、预留、绑定和任务，工作器再访问 Cloudflare；不跨 HTTP 持有数据库事务。Zone 写入串行，节点任务保持既有串行约束；部署等待关联 DNS 任务。

操作保存入队凭据版本。新的显式重试固定使用当前已验证连接版本，原操作保留历史版本；重试继续使用原操作标记，避免重复创建。发布新凭据先验证候选版本对启用 Zone 的读取能力，成功才切换连接，失败保留旧版。归档、引用和删除保护接入现有凭据中心。

创建附带操作标记。超时、重启或结果提交中断后先核对远端；不盲目重建。更新/删除前比较远端当前可编辑字段与基线，外部修改时停止。删除已不存在记录按成功处理。双栈部分成功保留逐项结果，重试失败项。

网络、429、5xx 最多自动执行三次。尊重数字或 HTTP 日期形式的 Retry-After，不缩短较长等待；超过一天的等待交由手动处理。权限、参数和冲突错误直接失败。刷新可核对终态失败操作，不能覆盖正在排队/执行的写入。

解析检查分别记录管理服务递归结果和权威结果及时间；支持 CNAME flattening。检查等待采用延迟任务，最长十分钟，不承诺全网缓存同步。

### 发布与回滚

新连接设置先作为目标。迁移以当前对外值回填已部署节点的已发布快照，保证升级不改变现有订阅；未部署节点不产生快照。

部署、同步和回滚使用执行修订的连接信息与证书设置进行检查，成功后事务提交已部署修订和连接快照。订阅使用已发布信息，失败保持原地址。已知历史外部 DNS 记录在回滚时也需验证；已删除记录提示修复，不自动重建。

更换域名保留旧记录。直接修改当前域名的 IP 仍会影响现有连接；保存旧域名不能保存其旧 IP。部署沿用已有服务重启机制，不承诺零中断。

### 删除与解绑

解绑提交替代公开地址，保留记录。当前绑定或已发布地址仍使用的记录不能删除、改名、变更类型或开启代理，须先完成地址切换。删除节点及仅移除管理记录均保留 DNS；未完成/结果不明的 DNS 写入需先完成或核对。连接有 Zone 或操作/批次历史时拒绝删除。ACME challenge TXT 始终由 Hysteria 管理。

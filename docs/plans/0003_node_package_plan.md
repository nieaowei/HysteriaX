# 节点有效期、流量额度与自动停用

## 概要

为节点增加到期时间、整机流量额度和计费周期。默认提前 7 天、已用流量达到 80% 时提醒；到期或额度耗尽后拒绝新代理连接并断开现有连接，续期或额度重置后自动恢复。

提醒同时显示在应用内和 macOS 系统通知中。限制判断、统计和自动停用由服务端执行，Mac 应用关闭时仍生效。

## 配置与接口

- 新建及编辑节点表单增加“有效期与流量套餐”：可选到期时间、流量额度、固定套餐/月度周期、月度重置日、计费时区、已有用量、网卡和计费方向，以及可修改的提醒阈值。
- 默认自动识别默认路由网卡，支持手动指定单个网卡；计费方向支持出站、入站、双向，默认双向。界面显示实际采集网卡。
- 月度周期默认使用 `Asia/Shanghai`，重置日支持 1–31 日；不足该日期的月份使用月末，在当地时间零点重置。固定套餐提供手动重置和用量校正。
- 在 `openapi/openapi.yaml` 增加节点套餐配置和只读用量状态；创建、查询、更新节点接口支持这些信息，新增节点用量校正/重置接口。写操作沿用修订号校验和审计记录。
- PATCH 中省略套餐配置表示保留；提交完整套餐配置可清除到期时间或额度。用量修改通过专用接口完成，普通保存不重置用量。
- 添加数据库迁移，持久化套餐、周期、网卡基线、采样记录和提醒事件。已有节点默认不限时、不限流量。
- 通过现有生成脚本更新 Swift DTO；保留当前未提交改动。套餐修改不下发 Hysteria 配置，也不触发服务重启。

## 统计、提醒与访问控制

- 新增独立的服务端网卡采集任务，复用可信 SSH 连接，读取 Linux 启动标识及网卡收发计数。每个节点约每 10 秒采样，限制检查独立运行，避免 SSH 失败阻塞到期判断。
- 首次采集建立基线，仅累计此后的增量；已有消耗通过手动录入补齐。网卡自动识别结果持久化，网卡变化、远端重启或计数下降时重新建立基线并记录统计缺口，不将旧计数重复计费。
- 用量包含所选网卡上的其他服务流量，与现有用户 Hysteria 配额统计分别保存。节点停用代理后继续采集。
- 周期切换和用量校正在事务中完成，防止重复重置或并发采样覆盖校正。跨月采样增量统一计入采样完成时的周期；界面说明这是本地估算，可能与供应商账单有差异。
- 服务端持久化临近到期、已到期、流量预警、额度耗尽事件；每个有效期或计费周期的每种事件只提醒一次。恢复正常后解除当前警告，续期或新周期重新启用提醒。
- 节点列表及总览显示剩余时间、已用/总额、下次重置时间和警告；详情显示采样时间、统计缺口及停用原因。
- macOS 使用现有定时刷新获取提醒，按管理服务地址和事件 ID 持久化去重。系统通知权限在启用通知时请求；权限被拒绝时继续显示应用内提醒，离线缓存不触发新通知。
- 节点受限时，认证接口拒绝普通用户，订阅过滤该节点，并仅对该节点安排断开连接任务，不改变用户在其他节点的权限。短期部署探测凭据保留现有用途。
- 断开任务沿用现有队列及重试机制，执行前重新检查限制，避免续期后旧任务误踢连接。续期、校正或周期重置后，仅在所有节点限制均解除时自动恢复；用户自身的禁用、到期和配额限制仍生效。

## 验证与验收

- 验证创建、编辑、清除限制、修订冲突、非法额度和阈值，以及旧节点迁移和客户端缓存兼容。
- 测试三种计费方向、首次基线、重复采样、网卡更换、重启、计数下降、SSH 失败及并发用量校正。
- 测试月末、闰年、时区边界、服务端停机跨多个周期和固定套餐手动重置。
- 测试提醒阈值边界、事件去重、续期重新提醒、通知拒绝及应用重启。
- 集成验证到期/耗尽后的认证拒绝、订阅过滤、已有连接断开、失败重试和恢复；确认其他节点及用户配额不受影响。
- 执行 Rust 检查和测试、OpenAPI/Swift 生成一致性检查及 macOS 构建；在测试节点验证真实网卡流量和代理断开。发布顺序为服务端迁移与更新，再更新 Mac 客户端。

## 默认边界

- 自动停用只控制 Hysteria 代理，不关闭 SSH、整机或其他服务。
- 采集失败保留已知用量并显示陈旧状态；不凭未知流量判定耗尽，到期限制仍执行。
- 流量耗尽判断存在采样延迟，断开连接依赖远端可达；界面显示待断开或失败状态，不承诺供应商额度绝不超出。
- 系统通知仅在 Mac 应用运行并联网时送达；重新连接后补发仍有效且未通知的提醒。

# 订阅模板配置工作台重构

## 1. 目标与范围

采用“主窗口模板 Table + 独立配置工作台”，字段详情统一使用原生 `Form`、`Section` 和 `.formStyle(.grouped)`。

本轮完成完整工作台，包括复杂集合的“列表 + 详情”编辑。采用手动保存草稿，关闭窗口、退出应用时提醒处理未保存修改。沿用现有 API、模板文档结构和两种配置格式的校验语义。

## 2. 界面与交互

### 模板管理页

- 使用原生 `Table`，列为：名称、格式、发布版本、编辑状态、默认标记、更新时间。
- 支持名称搜索、格式筛选、列排序；单击选中，双击、回车或点击“编辑”打开窗口。
- 工具栏提供新建、刷新；选中项菜单提供编辑、复制、重命名、设为默认、导出和归档。
- 编辑状态来自本地编辑会话，展示未打开、无本地修改、未保存、保存中或失败；不根据修订号推断是否存在未发布修改。
- 保存、发布、重命名、默认设置和归档成功后，同步刷新管理页。

### 独立编辑窗口

- 不同模板可同时编辑；同一服务、同一模板重复打开时激活已有窗口。
- 标题展示模板名称、格式及所属服务。默认尺寸 1200×800，最小 920×640，初始尺寸受屏幕可用区域约束。
- 顶部工具栏提供编辑层选择、可视化／源码切换、撤销重做、校验、保存草稿、发布和预览显隐。
- 左侧为原生模块导航，中间为编辑区，右侧为预览，底部为诊断摘要与可展开的问题列表。
- 窗口宽度达到 1100 点时允许并排预览；较窄时通过工具栏打开预览面板。

### 模块与 grouped Form

导航固定为基础配置、DNS、入站与 TUN、代理组／出站、分流规则、节点注入、平台覆盖、高级配置、版本历史。

- 按格式建立客户端字段分组映射：DNS 对应 `dns` 等路径；代理组／出站对应 Mihomo 的 `proxy-groups`、`proxy-providers`，以及 sing-box 的 `outbounds`、`endpoints`；分流规则对应 `rules`、`rule-providers`、`sub-rules` 或 `route`。其余字段归入对应基础、入站模块或高级配置，确保字段没有遗漏或重复入口。
- 中间表单由一个 grouped Form 承载，用 Section 划分功能组。简单字段使用系统 Toggle、Picker、TextField；对象通过子分组展开，避免逐层叠加 GroupBox 和嵌套 Form。
- 字段显示名称、原始配置键及必要说明；平台层保留“继承／设置／移除”状态。恢复默认、显式 `null` 等操作收进字段菜单。
- 代理组、出站、规则集、分流规则和节点注入使用集合列表，选中后在下方显示 grouped Form 详情；支持新增、删除和上下移动，保留规则原有顺序与引用保护。
- 动态节点连接参数保持只读。未知字段保留原值并提供源码入口，不生成未经验证的控件。
- 字段搜索覆盖所有配置模块；结果显示路径，点击后切换模块、展开对象或集合项目并定位字段。

### 平台、预览与历史

- 编辑层与预览平台独立选择。平台覆盖页列出所选平台已设置、已移除的字段，并提供跳转及恢复继承操作。
- 节点注入和版本历史属于模板整体，不受编辑层选择影响。
- 预览分为最终配置、字段来源、平台差异，复用现有用户、平台、内核版本和凭据显示选项。
- 文档、源码、预览条件变化后立即标记预览过期；旧请求结果不得覆盖新状态。
- 诊断按错误、警告分组，点击定位对应层、模块和字段。
- 历史版本集中在独立模块，提供结构化差异和现有回滚操作。发布前校验并展示相对当前发布版本的差异；有错误时阻止发布，确认后保存并发布。

## 3. 状态与接口调整

- 拆分模板列表状态与编辑状态。新增可编码、可比较的编辑标识，包含规范化服务地址和模板 ID；编辑会话注册表按此标识管理窗口及模型。
- 每个模板独立持有文档、基线、源码缓冲、撤销重做、诊断、预览、冲突和历史数据；窗口内导航与展开状态也独立保存。
- 编辑窗口绑定创建时的服务身份。主窗口切换服务后，原窗口保留本地内容并暂停远端操作；切回原服务后重新核对会话及修订号，有冲突时保留本地内容并进入冲突流程。
- 异步操作携带会话及文档代次，忽略已关闭窗口、旧连接和旧预览请求的返回结果。
- 模式切换、切层或离开源码编辑区前同步源码；解析失败时停留原处并保留原文。源码继续使用原生编辑器，不引入第三方依赖。
- `⌘S`、撤销重做等命令只作用于当前活动编辑窗口；源码及文本控件保留系统文本撤销行为。
- 关闭窗口提供“保存并关闭／放弃修改／取消”；保存或解析失败时取消关闭。应用退出统一处理全部未保存会话，任一保存失败则取消退出。
- 保留导入映射审核、完整模板导出、平台整数组覆盖、显式空值和引用重命名／删除保护；不修改公开 API 或数据库结构。

## 4. 验证与验收

- **状态隔离**：同时编辑两个模板，保存、撤销和预览互不影响；不同服务下相同模板 ID 不串用数据；重复打开同一模板只激活已有窗口。
- **生命周期**：覆盖关闭取消、保存后关闭、放弃关闭、退出时批量保存，以及无效源码、断网、修订冲突导致的关闭失败。
- **数据兼容**：回归 Mihomo 与 sing-box，覆盖继承／设置／移除、整数组覆盖、规则顺序、引用保护、未知字段、`null`、`false`、`0` 和大整数保真。
- **功能链路**：验证表格打开窗口、搜索定位、集合编辑、平台覆盖、预览失效、诊断跳转、保存、发布、历史对比、回滚及导入导出；确认保存草稿不会改变已发布订阅。
- **界面**：在 920、1100、1350 点宽度检查布局及预览切换；检查深浅色、长模板名、空列表、加载失败和键盘操作，确保控件无越界。
- 更新隔离 UI 测试入口，使其覆盖与正式应用相同的编辑窗口场景；运行现有订阅客户端回归和 UI 回归，同时验证正式 Xcode Debug／Release 与 SwiftPM 构建。新增源码同步纳入正式 Xcode 工程。

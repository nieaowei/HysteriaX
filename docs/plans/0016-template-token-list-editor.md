# 0016 简单列表标签输入

日期：2026-10-20

## 目标

自由输入的简单列表使用标签编辑器，保留一行一项的批量编辑能力；枚举和已有对象引用继续使用 checkbox。

## 实施

1. 使用带稳定 UUID 的标签草稿，支持重复值的独立编辑、删除与排序，保持原数组顺序和 JSON 数据类型。
2. Enter 添加，点击标签后修改，× 删除；多行粘贴进行原子解析，任一整数无效时保留输入且不改原配置。Esc 取消当前输入。
3. 标签自动按可用宽度换行，支持同字段内拖动排序，右键提供上移、下移操作。
4. 标签模式与批量编辑可切换。正则、URL、多行字符串、长值以及超过 50 项的数据默认使用批量编辑；批量输入无效时保留缓冲并禁止切换模式。
5. 外部更新和撤销/重做同步标签身份与内容，保留重复项、原有空字符串和带换行的字符串；不引入全局空值清理行为。
6. 为提示、编辑模式和删除操作补充中英文文案。

## 验证

- `scripts/verify-subscription-client.sh`：重复值身份、删除、双向移动、替换、多行粘贴原子性、整数与 UInt64 保真，以及原有模板客户端测试。
- `scripts/verify-template-picker-ui.sh`：真实 SwiftUI 标签列表在 360/640/900 点宽度下布局，外部内容变化、空值/换行保留和撤销/重做，以及原有复杂字段切换回归。
- macOS Debug 构建、`git diff --check`。

拖放排序通过同字段会话标识限制来源，避免跨字段拖放意外修改配置。

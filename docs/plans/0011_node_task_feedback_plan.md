# 节点操作与任务反馈优化

日期：2026-10-07
状态：已实施

## 实施内容

1. 节点操作接口返回任务回执，节点页先展示提交状态，再使用回执展示排队状态，随后刷新服务端数据。
2. 以节点 ID 关联任务，按执行中、排队中、最近完成的顺序展示；按最终要求移除节点列表的任务列。
3. 移除详情标题区的任务提示。将“当前与最近任务”放在“套餐与流量”上方，两者使用同一列并保持等宽，最多展示三条，保留可点击的任务名称、状态和右侧提交时间，仅活跃任务或失败任务附一行阶段或原因；省略目标版本和分隔线。提交反馈统一放入该区域。
4. 点击任务名称直接跳转到对应任务详情，复用已有初始选择机制；右侧显示简短提交时间，悬停显示完整时间。
5. 提交期间及相关 SSH、部署、同步、回滚、卸载任务活跃时禁用重复节点操作；失败后解除本地提交状态。断线显示快照提示，切换服务清理提交状态。
6. 使用现有事件刷新和定时刷新同步任务状态，不显示未经服务端提供的进度百分比。

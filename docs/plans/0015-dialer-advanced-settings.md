# 0015 拨号字段收敛为高级设置

日期：2026-10-20

## 目标

将拨号字段统一收入“对象名称 高级设置”折叠区，默认收起，保留现有字段顺序与草稿数据。

## 实施

1. 共用 `TemplateFieldLayout.dialerFields` 识别拨号字段。要求存在 detour、bind_interface 或 connect_timeout 等连接属性，避免将规则中的 network_type 匹配条件误收入拨号设置。
2. 复杂对象编辑器与内联对象表单使用共用的 `TemplateDialerSettings`，按对象名称显示标题，展开状态保存在编辑会话中。
3. 时间同步等直接展开到主表单的对象，也将同一对象的拨号字段合并为对应的高级设置区。
4. 诊断定位到拨号字段时自动展开，并保留原有滚动定位与字段编辑逻辑。

## 验证

- macOS Debug 构建。
- 字段分类、拨号顺序和规则匹配字段排除测试。
- 真实 SwiftUI 编辑器回归：默认收起、诊断定位自动展开、类型切换和撤销/重做。
- `git diff --check`。

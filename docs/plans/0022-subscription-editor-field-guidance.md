# 0022 订阅编辑器字段说明与文档定位

已实施，2026-10-20。

## 依据与范围

承接 0019–0021 的文档驱动编辑器，检查固定 sing-box v1.14.2 字段目录与官方配置文档。补齐字段说明入口和文档定位；保持已有配置结构、字段分组及平台策略。

## 实施

1. 有上下文说明或文档默认值的字段提供信息按钮，点击展示说明、对应文档及版本基线。查看说明不会将默认值写入草稿。
2. 文档入口优先使用协议专有字段，再查共享监听、拨号、UDP NAT、HTTP/2 与 QUIC 字段，修正 TUN `netns` 被误导向拨号页面的问题。
3. 规则动作参数依据当前动作 Schema 跳转到动作文档；同名匹配条件仍指向规则文档。域名解析器子字段指向 DNS 动作说明。
4. 已知字段定位到页内标题，包括 OpenVPN 嵌套 TLS 字段；未知字段回退到所属页面。生成目录记录组合标题及重复标题；重复标题回退整页，TLS 保留整页入口，避免猜测标题后缀而跳转到错误方向。
5. 帮助说明按对象上下文选择，避免规则动作套用拨号专用说明；预解析字段目录，避免每次生成文档链接时重复拆分标题。
6. 补充中英文文案和订阅编辑器说明文档。

## 验证

- 客户端模型回归：文档归属、嵌套标题、同名字段、未知字段回退、上下文说明、默认值不落盘，以及现有模板语义检查。
- SwiftUI 回归：类型切换、条件字段、撤销重做、HTTP Client、集合删除与大列表；独立原生界面实际点击信息按钮并验证弹窗打开且草稿不变。
- macOS Debug 构建、双语字符串格式和 `git diff --check`。

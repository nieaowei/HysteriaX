# 0006 用户列表额度与用量合并

日期：2026-10-04

## 目标

将 macOS 客户端用户列表的用量、额度合并为渐变进度条，不限额度使用无限图标。

## 实施步骤（已完成）

1. 将 `UsersView` 中两个表格列合并为「用量 / 额度」，设置最小列宽保证数值可读。
2. 与概览页保持一致，保留系统线性 `ProgressView` 的细进度底槽和尺寸，在上方显示「已用 / 总额度」。通过覆盖填充层按比例显示蓝色到青色渐变，达到 90% 时改为橙色到红色渐变。
3. 不限额度显示已用量和 SF Symbols `infinity` 图标，进度底槽保持空置，不计算百分比，也不显示满格占用。
4. 将有限额度的进度限制在 0–100%；零额度显示满格，超额保留实际用量。提供完整的悬浮提示和辅助功能描述。

## 验证

- `git diff --check`：通过。

本次为客户端显示修改，无服务部署。

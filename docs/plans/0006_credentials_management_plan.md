## 已确定的目标

- 完整入口：SSH 私钥/口令、密码、TLS 证书/私钥、CA、ECH、DNS 凭据、通用 API Token，以及管理员/用户/订阅凭据。
- 保留现有数据并迁移，允许破坏数据库和管理 API 兼容性；服务与客户端配套升级。
- 新版本自动更新全部当前引用；历史配置固定版本；目标与实际生效版本分别追踪。
- 用户/运维人员先在远端授权公钥、修改密码或创建第三方 Token；产品不自动修改远端授权或密码。
- 运维秘密导入后不回显，公开证书允许读取；管理员 Token 仅创建时显示；订阅复制与导出保留。
- 本机登录仍用 Keychain，主密钥及数据库启动密码继续外部配置。
- 完成测试服务器部署验收，本地构建镜像并推送，再由服务器使用该镜像。

## 数据与执行模型

凭据、不可变加密版本和更新批次持久化到 PostgreSQL。SSH 和 mTLS 分配有明确的凭据 ID/版本引用；代理配置与历史快照使用 `credential://<id>/<version>/<field>`。TLS 身份包含配对证书与私钥，DNS 身份包含完整服务商配置。用户 mTLS 材料限定所属用户。

初始化在单实例锁下、工作线程启动前事务性转换 SSH、证书/ECH 资源、DNS 配置、mTLS 及历史引用，删除旧秘密字段。迁移不触发节点部署。历史资源保留原远端文件名，迁移不更改既有配置的实际内容或部署摘要。普通 ACL/GeoIP/GeoSite 继续使用节点资源。

发布版本固定受影响对象并创建持久化任务。SSH 验证新凭据及主机指纹后切换；TLS/ECH/DNS 创建配置版本并同步，批次跟踪实际同步结果；mTLS 更新分配并跟踪断开旧会话的任务。部分失败不撤销其他成功；仅最新、未归档版本的失败项可重试。节点/用户并发编辑冲突时拒绝覆盖。

应用完成标记与绑定修改或后续任务在同一事务提交，处理“提交后、任务结果保存前崩溃”的恢复，不重复修改版本或重复创建后续任务。回滚解析原凭据版本，管理连接继续使用当前已验证 SSH 凭据。

归档保留已有使用，禁止新增引用/发布。当前、已部署、历史和未完成任务引用阻止删除；无引用时允许删除并保留任务/审计元数据。删除用户会归档其 mTLS 材料。

## 接口与客户端

直接修改 v1 管理契约，版本维持 1.0.0，管理路由为 `/api/v1`；订阅、健康和 Hysteria 回调 URL 稳定。新增凭据 CRUD、版本发布、引用、批次与重试接口；节点 SSH 和用户 mTLS 写入接受引用，拒绝旧内联秘密字段。服务端保护当前请求使用的和最后一个管理员 Token。

macOS 新增“凭据”侧边栏、列表/筛选、详情、引用跳转、版本发布、批次结果与重试、公开证书、信息编辑/归档/删除。节点和用户表单可选择或就近创建凭据。设置页跳转凭据中心。只缓存元数据，离线禁止详情读取和写入。

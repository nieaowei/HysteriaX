# 0008 修正流量进度条布局

日期：2026-10-04

## 问题

系统 `ProgressView` 的布局区域比可见底槽高，覆盖层按整个区域的高度绘制渐变胶囊，导致填充过粗；零进度的原生控件还会留下蓝色端点。

## 实施步骤（已完成）

1. 共享组件改用专用 `ProgressViewStyle`，统一绘制底槽和填充，保持数值在上、细条在下的布局。
2. 底槽和渐变填充固定为 4 点高度，并裁剪到同一个胶囊形区域。
3. 零进度、不限额度和未知用量不绘制填充，消除蓝色端点；正常蓝青渐变和高用量橙红渐变保持不变。

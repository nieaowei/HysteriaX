# 0011 复杂字段编辑体验

## 目标与选择

按用户选择的“列表＋宽编辑面板”替换狭窄的多层展开编辑，保留现有本地草稿、保存、撤销、平台覆盖和引用保护机制。

## 实施步骤（已完成）

1. 对结构化数组显示名称、类型及地址摘要，集中提供新增、排序和删除；按 schema 类型新增项目，并在宽面板编辑详情。
2. 对象详情使用独立表单，按标识、远端地址、认证、协议、传输和网络连接分组。字典支持直接编辑简单值、进入复杂值详情，并阻止新增同名键覆盖原值。
3. 简单字符串数组改用每行一项的编辑器，支持粘贴多行和插入可选引用；保留文本缓冲中的末尾换行，并同步撤销及外部值变化。
4. 补齐通过 schema 引用声明的类型选择；切换已知类型时保留公共字段和未知扩展值，移除旧类型专属字段。无法识别的原类型继续保留其字段。
5. Mihomo 规则与节点注入统一采用项目列表和宽编辑面板，保留专用规则控件、节点过滤和排序兜底选项。
6. 保留诊断定位：打开对应项目及嵌套对象，并在详情表单中滚动到目标字段。

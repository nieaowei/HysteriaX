# 0012 订阅模板改为单份配置

实施日期：2026-10-19。

## 目标

移除平台分层编辑，统一编辑一份原生配置；平台差异通过字段名旁的适用平台标签表达。

## 已实施

1. 移除编辑目标选择器和“平台覆盖”导航，表单、源码、引用重命名均围绕一份配置。
2. 根据字段目录的平台规则生成标签，支持通配路径和与当前字段值有关的规则。简单控件、复杂字段的 Section 标题、类型选择和固定类型字段均显示适用平台。
3. 新建及原生配置导入使用第 2 版模板文档，禁止携带平台覆盖。第 1 版文档及历史发布版本继续按原语义读取。
4. 第 2 版文档在生成订阅时按目标平台适配，保留可编辑原文；不支持的字段、透明入站或平台专属匹配规则仅从输出中排除。预览返回排除记录，类型、范围、依赖与引用校验继续生效。
5. 旧模板包含实际平台差异时，展示一次性转换页面，由用户选择保留的配置并查看完整差异。转换只修改本地草稿，可以撤销；未知字段、显式空值与节点注入保留在所选配置中。没有实际差异的旧模板直接升级。
6. 更新客户端回归、服务端模板测试及 UI 测试用例和夹具。

## 验证

- macOS Xcode Debug 构建通过。
- `scripts/verify-subscription-client.sh` 通过，覆盖平台标签匹配、旧模板转换及撤销、未知值保留。
- 使用临时 PostgreSQL 容器运行服务端订阅模板测试：28 项全部通过，包含保存发布、历史版本、导入导出和公开下载。
- 使用临时服务运行 `scripts/verify-subscription-template-ui.py --client`：源码、预览、保存发布隔离、回滚和导入导出通过。
- UI 测试源文件 Swift 类型检查、字符串资源格式检查和 `git diff --check` 通过。

## 兼容与边界

- macOS 与服务端需要使用支持第 2 版文档的配套版本。
- 旧模板的不同平台配置不会自动合并或静默丢弃，转换前需在应用内选择保留的配置。
- 未更改现有已发布版本，未部署服务，未运行屏幕自动化 UI 测试。

# 0019 配置文档驱动的通用编辑器优化

已实施，2026-10-20。

## 依据与范围

以用户提供的 [配置文档](https://sing-box.sagernet.org/zh/configuration/) 为入口，并对照 sing-box v1.14.2 自带 docs/configuration。保留已有导航分配、用户指定的字段类型及单配置编辑方式。只增强当前固定 Schema 已支持的配置。

## 实施

1. 新增 TemplateEditorGuidance 集中管理文档入口、字段分组、顺序、默认预览、输入示例和条件显示。根配置均有对应文档入口，具体对象按类型定位；缺少专属文档的类型回退至其分类索引。
2. 规则分离动作和匹配条件，并细分域名/规则集、IP、端口、进程/用户匹配；规则集分离来源、下载设置与规则内容。TLS 分离基础字段、证书认证和 ECH/Reality/uTLS/ACME，WireGuard 分离接口与对端。
3. 功能对象的 enabled 控制后续字段。DNS HTTPS/TLS/QUIC 等自动使用 TLS 的场景不展示无效的 enabled 开关。detour、TCP keep-alive、fallback 网络策略、分片和 Clash UI 等按适用条件显示；隐藏不删除已有值。
4. DNS 端口、NTP 端口/间隔、URLTest 参数、拨号保活等以文档默认值预览，不写入未编辑字段。增加时长、URL、绑定地址、证书路径的输入示例与上下文帮助。
5. 复杂数组及 predefined 概览使用自然行高，移除固定高度的嵌套 List。保留选择、编辑、排序、删除及撤销。
6. 增强规则、证书提供者、WireGuard、网络命名空间、代理组摘要，限制摘要字段，避免包含私钥等凭据。
7. 展平嵌套联合类型，直接选择共享证书或具体证书提供者；Snell 类型名称包含版本，避免重复选项。

## 验证

- 模型测试：文档映射、条件显示、自动 TLS、默认值不落盘、类型选项、摘要字段范围及现有全部模板语义回归。
- 实际 SwiftUI：证书提供者、Snell、TLS 开关、HTTP Client、既有类型切换与撤销重做；20 项 predefined 列表自然高度和删除撤销。
- 集合回归：解析器、服务器和规则删除/撤销/重做；20 项服务器列表自然高度。
- macOS Debug 构建、字段分类覆盖及 git diff --check。

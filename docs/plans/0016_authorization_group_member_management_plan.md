# 授权组大量成员管理交互改造

日期：2026-10-07

## 目标

让单个授权组拥有数百到数千位成员时，仍能高效查看、添加、批量移除和核对变更，继续遵循现有授权并集、个人 mTLS、预览令牌及版本校验规则。

## 实施内容

1. 授权组页采用可拖动的左右分栏，左侧为紧凑授权组列表（名称、成员数、节点数），右侧显示完整高度的详情和成员表格；未选组时显示选择提示。列表宽度 180–240 点，右侧宽度由当前可用宽度减去左栏和分隔线宽度计算，避免原生分栏在最小窗口下只采用最小宽度造成留白；总宽度约束到当前可用区域，窄窗口的搜索/操作栏自动换行，次要组操作收进更多菜单。通用上下分栏组件保留原实现。授权组详情划分成员、节点、记录三个视图。成员使用原生 Table，提供名称/ID 搜索、状态筛选、排序、双击查看用户、右键操作。
2. 成员表格客户端分页，每页最多 100 人。区分当前页与全部匹配结果全选；显式合并可见选择，保留跨搜索和分页选择，支持仅显示已选。
3. 成员管理使用独立编辑草稿，同一窗口内切换成员、添加成员、仅看变更。添加入口仅列出非成员；支持批量移除、单项/多项撤销、固定变更人数摘要和取消草稿。
4. 保存前读取最新组详情，把用户明确添加/移除的差量应用于最新成员集合，保留其他管理员的修改和最新名称。继续使用版本及预览令牌提交。
5. 权限影响先按用户汇总，再展开节点；搜索并以每页 50 人显示。移除人数与实际撤权人数分别说明。个人证书按用户分组，可筛选待处理人员；缺失绑定继续阻止保存。
6. 补充中英文资源、Xcode 文件引用、5,000 位成员/20,000 条连接的逻辑验证及 201 成员/301 用户的隔离 UI 测试，更新使用文档。

## 验证

- `scripts/verify-authorization-groups-client.sh`：大组差量、跨页选择、局部撤销、未知用户、并发成员变更合并，以及既有 API 兼容性验证。
- `scripts/verify-localization.sh`：中英文资源覆盖、参数占位一致性和语言切换。
- `python3 scripts/verify-authorization-groups-ui.py`：跨页移除、跨搜索添加、撤销、取消、权限预览、个人 mTLS 阻止提交与创建组保存。
- `scripts/verify-vertical-split.sh`：分栏初始比例、拖动、切换、缩放。
- `./script/build_and_run.sh --verify`：Xcode 编译和启动。

## 边界

本次实施为 macOS 客户端交互改造，继续使用现有服务端全量接口；分页限制界面渲染规模，不减少接口返回量。服务端搜索/分页、名单导入与批量粘贴 ID 留作后续增强，无需部署服务或迁移数据库。

## 实施结果

上述六项已完成。客户端逻辑检查、中英文资源检查、分栏缩放检查、两项隔离 UI 测试及 Xcode 构建/启动验证全部通过。

- 大组逻辑规模：5,000 位成员、20,000 条用户—节点连接，覆盖跨页选择、局部撤销和并发成员变更合并。
- UI 夹具规模：201 位组成员、301 位系统用户，覆盖分页、多次搜索添加、移除/撤销/取消、权限预览、缺少个人 mTLS 绑定阻止保存，以及创建组提交。额外验证左右位置、成员表格可用高度和分页按钮不超出窗口边界；创建弹窗状态归页面共享状态所有，避免反复切换标签后的工具栏失效。
- UI 结果：`apps/macos/.build/authorization-ui-1791382963.xcresult`，两项测试通过；截图已导出到 `apps/macos/.build/group-fill-final` 并目视检查。
- 本地新版客户端已通过 `./script/build_and_run.sh --verify` 启动。

## 最小窗口修正（2026-10-08）

左侧列表采用普通列表并隐藏滚动背景，沿用内容区背景，去除侧栏材质。左右分栏按可用宽度计算，分隔线支持拖动及辅助功能增减操作。成员表格列宽按视口预算分配，包含系统单元格边距与滚动条，长 UUID 中间省略并可悬停查看完整 ID。

最后两项隔离 UI 测试均通过，夹具包含真实长度 UUID，新增验证详情右边界铺满、表格正常内边距、没有横向滚动条；实际客户端已在最小尺寸及左栏调宽后目视验证。

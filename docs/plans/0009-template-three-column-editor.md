# 0009 订阅模板编辑器三栏布局

## 目标

使用原生三栏 `NavigationSplitView` 展示模块导航、配置编辑、预览与诊断，隐藏窗口标题文字，将编辑和预览操作统一放入工具栏。

## 实施步骤（已完成）

1. 将模块导航抽为独立视图，由工作台持有唯一的三栏 `NavigationSplitView`；移除嵌套分栏和按窗口宽度切换的预览弹窗。
2. 中栏保留表单、源码、错误和冲突提示；右栏集中预览设置、预览输出和诊断定位。
3. 中栏工具栏提供平台选择、源码切换、撤销、重做、校验、保存、发布及模板操作菜单；右栏工具栏提供生成预览和导出。草稿状态移入工具栏。
4. 隐藏原生窗口标题文字，使用统一工具栏样式；继续维护逻辑标题，供窗口识别和辅助功能使用。
5. 更新现有布局回归，检查 920、1100、1350 点宽度下三栏并排、工具栏按钮位置及源码切换后预览仍可见。

## 验证

- SwiftPM 构建通过。
- Xcode Debug 应用构建通过（关闭代码签名）。
- 更新后的 UI 测试代码通过 Swift 6 类型检查。
- `git diff --check` 通过。
- 当前环境未设置 `TEST_DATABASE_URL`，完整 UI 回归尚未执行，三栏实际显示和工具栏在不同宽度下的布局仍需运行验证。

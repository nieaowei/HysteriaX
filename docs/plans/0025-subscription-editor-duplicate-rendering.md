# 0025 订阅编辑器重复渲染核查与修复

日期：2026-10-20。状态：已实施。

1. 核查类型选择器、内联对象、详情弹窗、专用组件、模块分组及自定义字段的渲染路径。
2. 将选择器已表达的判别字段归属集中到模型，修复 ACME `provider`、Snell 固定 `version`、内联 `type` 等重复显示；保留独立协议参数。
3. 纯对象联合在折叠概览中只提供编辑入口，类型切换集中到详情；字符串／对象等混合引用保留必要切换。
4. 验证全部含对象分支的命名联合定义，运行模型与原生视图回归、macOS Debug 构建和差异检查。
5. 保存专项核查报告并更新完整优化报告。

结果：以上步骤均完成。模型覆盖 18 个判别字段联合定义、115 个对象分支及另外两种混合引用；模型回归、原生视图回归、构建与差异检查通过。

详见 [专项核查报告](../audits/0025-duplicate-rendering.md)。

# 0028 缓存分域与历史/任务读模型

日期：2026-10-14。落实后续审查中明确的 P1/P2 项，保留 `/api/v1` 和精确延迟分位数。

## 实施内容

1. 0020 增加缓存依赖版本表与源表触发器。目录、用户状态、节点状态、流量、网卡、在线、探测、任务、审计等分别递增；读取按接口依赖组合选择版本，提交发布、回滚不发布。Redis 缓存格式命名空间升级为 2，避免旧键混用。
2. 修正探测计数的索引结束条件与边缘补算，只读取不完整分钟。历史读取按指标需求与窗口结束点判断是否需要更新周期，纯网卡流量不获取聚合写锁。精确 P50/P95 保持原始成功样本计算。
3. 0021 增加 `traffic_hour_totals` 与 `online_minute_totals`。源变更标记脏桶，后台增量重算；查询使用完整粗粒度桶与细粒度边缘，脏桶回退分钟表/周期表。在线平均按有效周期数加权，并保留未知、成功空采样、覆盖率、峰值与不完整标记。
4. 0022 增加任务状态、节点撤权及失败分钟计数，同事务维护。概览、节点/套餐展示与无搜索任务总数直接读模型；关键词精确 COUNT 仍查询原表，24h 失败边缘保持原有时间条件。
5. 0023 增加重试链成员与失败提醒状态。状态/重试关系变化只标记受影响任务，后台定位旧/新根并重建相应链；待处理时概览回退原递归查询。成功叶节点、取消/进行中继承错误与失败种子时间窗保持原规则。
6. DNS、授权组、资源元数据使用分域的 60 秒缓存；终态任务/批次按实际内容与关联依赖摘要缓存五分钟，重试链接/关联名称改变立即换键。凭据静态目录缓存五分钟，读取时更新用户资格、剩余天数和使用时间，再排序分页。
7. 订阅成品和静态连接投影缓存五分钟，Token/用户/节点资格仍逐次检查。冷生成复用批量资格检查，统一加载 ECH/个人 mTLS 材料；投影不含服务器认证、SSH或 ACME 管理配置，Redis 内容继续加密。
8. 授权组目录增加内部快照缓存，外层响应超过大小上限时仍可复用快照；当前列表/详情契约保持一致。新增按路由模板的计算/复用次数、服务器错误与总/最大耗时，不记录身份、查询词或原始 ID。
9. 0024 增加任务/批次单调对象版本，终态内容摘要与对象版本共同组成缓存键，避免状态往返和重试删除造成键复用。历史缓存键包含当前 UTC 分钟，窗口跨分钟时直接换键。

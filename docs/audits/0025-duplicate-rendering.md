# 0025 订阅编辑器重复渲染核查

日期：2026-10-20。范围：macOS 订阅编辑器，保持现有 sing-box 1.14.2 与 Mihomo Schema。

## 发现与修复

| 入口 | 问题 | 处理 |
| --- | --- | --- |
| ACME DNS-01 验证 | 顶部选择供应商后，下方又显示同一个 `provider` 常量 | 由顶部选择器控制 `provider`，不再生成第二行；顶部标签也使用 `provider` |
| Snell 出站 | 类型选项已包含 `snell · 4` / `snell · 6`，下方仍显示同一个 `version` 常量 | 类型选择器同时控制 `type` 与固定 `version`，参数区不重复显示 |
| 内联传输等联合对象 | 通用内联表单有类型选择器，子字段又显示 `type`；此前只修复了独立弹窗 | 内联与弹窗共用判别字段归属规则，已被选择器表达的字段不再生成子控件 |
| 折叠的纯对象联合 | 概览和详情各有一个相同的类型选择器 | 概览保留编辑入口，类型切换集中到详情；不影响内联表单 |
| 普通、逻辑规则及网络命名空间 | 普通分支可能用枚举声明 `type`，逻辑分支用常量声明，容易产生不同的重复行为 | 同时覆盖常量和枚举，路由、DNS、嵌套匹配规则、规则集规则等入口统一处理 |

`TemplateSchema.variantFieldKeys` 按实际选项标题确定选择器已经表达的字段。它不会一律隐藏名字为 `provider`、`protocol` 或 `version` 的参数。例如证书提供者类型为 ACME 时，ACME 服务商的 `provider` 仍可填写；OpenConnect 的版本、HTTP 客户端的 HTTP 版本、规则的匹配协议和动作仍是独立配置。

折叠入口只对所有分支都是对象的联合委托类型编辑。共享 HTTP 客户端、共享证书提供者、字符串／对象域名解析器等混合引用保留必要的切换入口；HTTP 客户端的“自定义配置”选择不接管 `version`。

## 其他已核查入口

| 范围 | 核查结果 |
| --- | --- |
| HTTP 客户端基础信息、版本、headers、HTTP/2、QUIC、TLS 和网络连接 | 专用组件与通用对象组件互斥；专用字段不进入“其他选项”，未发现额外重复控件 |
| HTTP 客户端 TLS 分组 | 各分组字段无重复；未归类字段进入剩余分组，已有回归检查字段覆盖与唯一性 |
| 普通字段与高级连接设置 | 使用互斥字段集合分区，不在两处同时编辑同一路径 |
| 主模块的根对象展开 | 每个属性只生成一个路径，再按分区分组，未发现额外重复项 |
| 动态自定义字段 | 排除已知属性；自定义编辑与未知字段说明分支互斥 |
| 缓存文件开关、DNS 乐观缓存、Mihomo 规则、节点注入 | 专用和通用入口互斥，未发现额外重复控件 |
| 标签与可选值、集合标题与摘要、保留字段说明 | 分别承担输入、选值或摘要用途，不作为同一路径的重复配置控件删除 |
| 字符串／数字等标量联合 | 表示类型选择与实际值输入分别保留，例如 DNS 查询类型的字符串和数值表示 |

# 节点有效期与流量套餐

先更新管理服务（启动时自动执行迁移 0003），再更新 macOS 客户端。旧节点默认不限时、不限流量。完整数据库备份包含套餐、网卡基线、采样历史和提醒事件。

节点列表提供“服务器配置”和“代理配置”两个入口。“服务器配置”包含基本信息、SSH 连接和有效期与流量套餐；基本信息及 SSH、套餐和用量通过各自按钮独立保存。“代理配置”包含 Hysteria 监听、TLS、路由和资源等设置，使用“保存并同步”下发代理配置。在添加节点或服务器配置页设置到期时间、额度及已有用量；“校正用量”和“重置为零”分别用于对齐供应商用量和开启新套餐，均保留每月重置日。

流量单位为十进制 GB（1 GB = 1,000,000,000 字节）。默认每 10 秒左右通过可信 SSH 采集默认路由网卡，支持手动指定单个网卡，以及双向、仅出站、仅入站计费。自动检测同时支持 IPv4 和 IPv6 默认路由，无需安装额外的采集代理。最多同时采集四个节点；单次采集超时 30 秒，大量节点或 SSH 失败会增加实际间隔。

统计覆盖所选网卡的全部流量，包括 SSH、系统更新及其他服务，独立于用户的 Hysteria 配额统计。首次采集不计入机器启动以来的历史流量，需手动录入供应商的已有用量。用量校正、重新启用流量限制或修改网卡/计费方向会重新建立采集基线；到下一次成功采样之间的流量无法精确归属。远端重启、网卡变化和计数下降也建立新基线并记录缺口，不将旧计数重复计费。采集失败保留已知用量，恢复后按同一启动标识和网卡的计数增量补计。

月度额度按节点的 IANA 计费时区在指定日期零点重置，默认时区为 Asia/Shanghai；不足该日期的月份使用月末。遇到夏令时导致当地零点不存在时，使用当地零点起的第一个有效时间。服务端停机跨多个周期时，恢复后进入当前周期，不重复累计旧周期额度。跨周期采样增量统一归入采样完成时的周期；它是本地估算，可能与供应商账单存在差异。固定套餐用量持续累计，直至手动校正或重置。

默认在到期前 7 天、已用额度达到 80% 时提醒，可按节点调整。到期、耗尽和各预警事件按有效期/计费周期去重。主页右上角的通知按钮显示当前提醒数量，点击后在浮窗中查看详情；在设置中开启“macOS 系统通知”并授权后，应用运行且联网时发送系统通知，重新连接时补发仍有效且未通知的事件。通知授权被拒绝不影响应用内提醒。

限制判断独立于网卡采集和 Mac 应用运行。到期或额度耗尽后，管理服务拒绝普通用户的新连接、从订阅中隐藏节点，并为该节点的用户安排断开连接任务。SSH 和 Hysteria 服务保持运行，网卡统计继续采集。续期或额度恢复后自动允许代理，用户自身的禁用、到期和配额限制仍生效。未完成的旧断开任务在执行前重新检查限制，并在恢复时取消排队任务。断开失败会重试，界面显示待断开数量，具体错误可在任务记录查看。Hysteria 的 kick 在下一次代理流量回调时执行，因此空闲连接可能暂时仍显示在线；已经提交给 Hysteria 的 kick 标记无法通过其 API 撤回，恢复后可能需要一次重连。参见 [固定版本的上游实现](https://github.com/apernet/hysteria/blob/app/v2.12.3/extras/trafficlogger/http.go)。

采集和连接断开存在延迟，SSH 不可达时无法立即踢掉现有连接；未知流量不会被当作零用量或直接触发耗尽。供应商的整机额度仍可能继续被其他服务消耗。

## API

节点创建可提交 `package` 和 `initial_usage_bytes`。节点查询返回 `package` 和只读 `package_usage`，包含用量、采样时间、实际网卡、统计缺口、下一次重置、限制原因和当前提醒。

`PATCH /api/v1/nodes/{id}` 省略 `package` 保留原套餐；提交套餐对象整体替换配置，空到期/额度解除对应限制，不重置用量。套餐字段与默认值见 `openapi/openapi.yaml`。

`PUT /api/v1/nodes/{id}/usage` 接收 `expected_revision`、非负 `usage_bytes` 和可选 `reset`。`reset: true` 开启新的流量提醒周期，但不改变月度重置日。响应返回节点 ID 和新修订号。所有写入有修订校验和审计；额度更新与采样由数据库事务协调。

## 验证

- `cargo test --workspace`：计费方向、基线、并发校正、重置、到期、提醒去重、节点认证限制和迁移。
- `scripts/verify-node-package-client.sh`：客户端缓存兼容、输入及 API 编码、通知授权拒绝、发送重试和持久化去重。
- `scripts/verify-node-packages-live.py`：在独立 PostgreSQL schema 和一次性 Debian systemd 节点上验证真实网卡采集、真实 Hysteria 在线连接断开、订阅过滤和自动恢复。需要 `TEST_DATABASE_URL`、测试 Python 依赖和 Docker。先构建 `docker build --build-arg BASE_IMAGE=debian:trixie -f scripts/fixtures/systemd-node.Dockerfile -t hysteriax-package-test:local .`，脚本自动清理测试节点和 schema。

## 实际部署状态

本次完成的是实现、隔离验收和发布物交付。没有执行真实线上数据库切换或替换用户正在使用的 macOS 客户端；这与本机完整升级／恢复试验分开记载。生产切换时仍按文档先停旧版本、保留完整备份和旧客户端，再迁移、校验、启动新版。生产连接数及内存按各服务的实际所在主机分别核算，不将同机 Docker 栈总限额或额外原生测试主机作为本次实现完成的条件。

# Hysteria 2 v2.12.3 server field coverage

The service accepts JSON with the fixed Hysteria 2 v2.12.3 lower camel case field names and renders accepted options as YAML. The root and nested field list follows the pinned [`serverConfig` definition](https://github.com/HyNetworks/hysteria/blob/app/v2.12.3/app/cmd/server.go) and the [official full server configuration](https://v2.hysteria.network/zh/docs/advanced/Full-Server-Config/). QUIC/UDP runtime limits follow the pinned [server core validation](https://github.com/HyNetworks/hysteria/blob/app/v2.12.3/core/server/config.go), and bandwidth units follow its [fixed-version parser](https://github.com/HyNetworks/hysteria/blob/app/v2.12.3/app/internal/utils/bpsconv.go). Unknown root and nested fields are rejected before deployment. HysteriaX stores the listener separately as node `listen_addr`, renders it as Hysteria's `listen`, and manages `auth` and `trafficStats` itself.

| Configuration section | Fields | Coverage |
|---|---|---|
| Listener | Hysteria `listen`; HysteriaX node `listen_addr` | Supports one port, comma-separated ports, and non-overlapping ranges. Port-hop nodes require the public port to match the first listener port and remote nftables/iptables; their service receives `CAP_NET_ADMIN`. Mihomo subscriptions map ranges to `ports` and use the 30-second hop interval. |
| Realms | `realm.stunServers`, `stunTimeout`, `punchTimeout`, `heartbeatInterval`, `insecure`, `ipMode`, `portMapping.enabled`, `portMapping.timeout`, `portMapping.lifetime`; HysteriaX `realm.connection.serverURL`, `token`, `realmID` | Server registration and native Hysteria client transfer passed against a local rendezvous. Mihomo v1.19.31 accepted mapped `realm-opts` but timed out on its live `/connect` request, so the API rejects Realm mode pending a compatible fixed client. |
| Obfuscation | `obfs.type`, `obfs.salamander.password`, `obfs.gecko.password`, `minPacketSize`, `maxPacketSize` | Both modes and packet-size bounds are validated. Gecko passed real Hysteria and Mihomo v1.19.31 TCP transfers with mTLS and ECH enabled. |
| TLS | `tls.cert`, `key`, `sniGuard`, `clientCA` | Certificate and private-key uploads are parsed as PEM; when both fields reference uploaded resources, the server verifies that the key matches the certificate before queuing sync. Resources deploy as `0640`. mTLS assignments require a PEM certificate/private-key pair, validate that the key matches, encrypt both at rest, and include both in no-store Mihomo subscriptions. |
| ACME | `domains`, `email`, `ca`, `listenHost`, `dir`, `type`; `http.altPort`, `tls.altPort`, `dns.name`, `dns.config`; legacy `disableHTTP`, `disableTLSALPN`, `altHTTPPort`, `altTLSALPNPort` | Challenge variants, alternate ports, and legacy fields are validated and editable. `domains` uses an add/remove list editor; DNS names are restricted to `cloudflare`, `duckdns`, `gandi`, `godaddy`, `namecheap`, `njalla`, `porkbun`, and `vultr`, with credentials edited in masked key/value rows. Modern `type` variants and legacy fields are rejected when mixed. |
| ECH | `ech.keyPath` | Must reference an uploaded encrypted `ech_key` resource. Hysteria receives the full key file; no-store Mihomo subscriptions receive its public `ECH CONFIGS` block as `ech-opts`. Real Hysteria and Mihomo v1.19.31 TCP transfers passed with ECH enabled. |
| QUIC | `initStreamReceiveWindow`, `maxStreamReceiveWindow`, `initConnReceiveWindow`, `maxConnReceiveWindow`, `maxIdleTimeout`, `maxIncomingStreams`, `disablePathMTUDiscovery`, `disableStatelessReset` | Every v2.12.3 field is type checked and editable. Non-default receive windows must be at least 16 KiB, initial windows cannot exceed maximums, non-default stream counts must be at least 8, and the idle timeout must be zero/default or 4–120 seconds. |
| Mimic | `enabled`, `interface`, `xdpMode`, `path`, `extraArgs` | Disabled mode and field types are validated. Enabling is rejected for the initial Mihomo compatibility profile. |
| Congestion and bandwidth | `congestion.type`, `bbrProfile`; `bandwidth.up`, `down`, `disableLossCompensation`; `ignoreClientBandwidth` | BBR/Reno, BBR profiles, loss-compensation policy, and the client-bandwidth boolean are validated and editable. Bandwidth accepts integer `b`/`bps`, `k`/`kb`/`kbps`, `m`/`mb`/`mbps`, `g`/`gb`/`gbps`, and `t`/`tb`/`tbps` rates using decimal prefixes; nonzero values must convert to at least 65,536 bytes per second. |
| Transfer options | `speedTest`, `disableUDP`, `udpIdleTimeout` | Boolean and duration fields are validated and editable. UDP idle timeout must be zero/default or 2–600 seconds. |
| DNS resolver | `resolver.type`; `tcp.addr/timeout`, `udp.addr/timeout`, `tls.addr/timeout/sni/insecure`, `https.addr/timeout/sni/insecure` | All four variants and their fields are validated and editable. |
| Sniffing | `enable`, `timeout`, `rewriteDomain`, `tcpPorts`, `udpPorts` | Fields are validated and editable. |
| ACL and Geo data | `file`, `inline`, `geoip`, `geosite`, `geoUpdateInterval` | Inline rules, ACL/Geo resource references, and update interval are validated and editable. Resources are encrypted at rest. |
| Outbounds | `name`, `type`; `direct.mode/bindIPv4/bindIPv6/bindDevice/fastOpen`; `socks5.addr/username/password`; `http.url/insecure` | Named direct, SOCKS5, and HTTP outbounds are validated and editable as an ordered list. The native form supports adding, removing, editing, and moving the default outbound; the full saved configuration is encrypted at rest. |
| Traffic statistics | `trafficStats.listen`, `secret` | Always generated on loopback with a per-node secret. |
| Authentication | `auth.type`, `http.url`, `http.insecure` | Always generated as the HysteriaX HTTP callback. |
| Masquerade | `type`, `listenHTTP`, `listenHTTPS`, `forceHTTPS`; `file.dir`; `proxy.url/rewriteHost/xForwarded/insecure`; `string.content/headers/statusCode` | File, proxy, and string modes and all listed fields are validated and editable. String response headers use a native key/value row editor. |

The config tests provide valid field-family fixtures for the editable settings, run each fixture through validation and YAML rendering, then assert that every configured option survives serialization. Coverage includes all ACME challenge variants and legacy fields, all resolver transports, both obfuscation modes, ACL resources and inline rules, every outbound kind, and all masquerade modes. Separate assertions reject invalid types, unknown fields, managed fields, mutually exclusive TLS modes, missing resources, and compatibility-gated features. The fixed Mihomo v1.19.31 parser check covers generated Hysteria2 subscriptions with Gecko, mTLS, ECH, and port ranges. A live Debian 13 arm64 test completed Hysteria and Mihomo TCP transfers with all four enabled and a 5-second client hop interval. The live Realm probe is documented in the compatibility profile; its Mihomo timeout keeps the feature disabled.

Duration validation accepts Go/Hysteria duration sequences such as `1m30s` and fractional units. QUIC and UDP idle-timeout checks enforce the pinned runtime bounds and preserve zero as Hysteria's default value.

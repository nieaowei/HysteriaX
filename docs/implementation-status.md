| P1: Management service | Implemented | Admin token lifecycle, encrypted secrets, optimistic revisions, CRUD/assignment/resource APIs, persisted jobs and events, resumable SSE, audit, subscription output, HTTP auth, and API version negotiation are wired. Before applying pending migrations to a non-empty SQLite database, startup writes a verified snapshot with mode-restricted permissions; migration acceptance confirms a version-0001 snapshot remains readable while the live database upgrades through version 0004, and a fresh install creates no empty snapshot. The usage API returns per-node sample times, aggregate freshness and gap counts, and pending or failed kick jobs per assigned node. Aggregate freshness becomes stale if any assigned node has missing or old samples, so a fresh sample on one node cannot mask missing data on another. Deployment jobs persist phase changes and redacted progress entries atomically with `job.progress` events; failure details are scrubbed against saved node and user credentials, configured passwords and URL credentials, ACME provider values, and mTLS certificate/private-key material before storage or return. Startup requeues interrupted jobs and writes recovery events atomically; database and process-level restart checks verify recovery, event persistence, worker claim, and retrieval of a progress log after restart. The API handles SIGTERM and SIGINT with graceful HTTP draining; the isolated Compose backup/restore integration confirms prompt container stop, restart, and readiness. The auth-isolation verifier creates a token with a 100-character Unicode label, uses it, confirms list responses omit token values, revokes it, and verifies it is rejected. The verifier also sends two simultaneous edits at one expected revision and confirms exactly one succeeds while the other receives HTTP 409. OpenAPI generates Swift request and response DTOs and binds every operation to its request/response types, method, path, and required query parameters. The generic API transport and dynamic JSON value codec remain shared handwritten components; regeneration drift is checked in CI. |

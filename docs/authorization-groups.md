# 授权组

在「用户」页面的工具栏中切换「用户 / 授权组」。授权组同时包含用户和节点；每位成员获得组内所有节点的访问权限。用户属于多个组时，权限取并集，同一个节点只出现一次。

## 管理方式

在授权组页创建组，选择成员用户和节点。后续通过「管理用户」和「管理节点」批量调整。用户页的「管理授权组」用于调整单个用户的所属组；节点权限旁显示所有来源组。

保存前会预览新增和移除的用户—节点权限。移除一个来源组不会撤销其他组提供的访问权限；只有最后一个来源被移除时才撤权。数据库权限提交后立即更新，在线连接断开由撤权任务执行，可在任务页查看结果。

需要 mTLS 的节点仍使用各用户自己的证书。新增访问权限时，按提示为缺少凭据的用户、节点选择个人证书身份；组内用户不共享证书。已有连接密码和证书不会因新增重复授权来源而更换。

用户自身的停用、到期、流量额度限制仍然生效。组没有独立流量额度、有效期或嵌套关系。

## 升级现有授权

升级时，拥有完全相同节点集合的用户自动合并到同一个「迁移授权组 N」。没有节点的用户不自动入组。原连接密码、证书绑定、订阅令牌和流量数据保留。

迁移组可改名并重新整理。注意：迁移后修改组的节点会影响组内所有成员。

升级后的服务只允许通过组修改节点权限；旧客户端的个人节点分配和移除操作会被拒绝，需要升级客户端。新版客户端连接旧服务时仍可使用原有个人分配流程。

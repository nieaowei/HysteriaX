# 授权组

在「用户」页面的工具栏中切换「用户 / 授权组」。授权组同时包含用户和节点；每位成员获得组内所有节点的访问权限。用户属于多个组时，权限取并集，同一个节点只出现一次。

## 管理方式

在授权组页创建组，选择成员用户和节点。后续通过「管理用户」和「管理节点」批量调整。授权组页采用左右布局：左侧选择授权组，右侧详情分为「成员 / 节点 / 记录」，成员表格支持名称或 ID 搜索、状态筛选和排序。分隔线可拖动调整左栏宽度，右侧会填满剩余空间。长用户 ID 会中间省略，悬停可查看完整值。双击成员或使用右键菜单可打开用户详情。用户页的「管理授权组」用于调整单个用户的所属组；节点权限旁显示所有来源组。

保存前会预览新增和移除的用户—节点权限。移除一个来源组不会撤销其他组提供的访问权限；只有最后一个来源被移除时才撤权。数据库权限提交后立即更新，在线连接断开由撤权任务执行，可在任务页查看结果。

需要 mTLS 的节点仍使用各用户自己的证书。新增访问权限时，按提示为缺少凭据的用户、节点选择个人证书身份；组内用户不共享证书。已有连接密码和证书不会因新增重复授权来源而更换。

用户自身的停用、到期、流量额度限制仍然生效。组没有独立流量额度、有效期或嵌套关系。

## 大量成员管理

成员表格每页最多显示 100 人。「选择」菜单明确区分当前页与全部匹配结果，跨搜索、筛选和分页保留选择；「仅显示已选」用于检查选中人员。当前分页在客户端进行，数据仍由现有全量接口读取。

点击「添加成员」进入非成员列表，多选后点击「添加所选」加入草稿。在成员表格中多选后可批量移除；右键菜单也提供移除入口。详情页的批量移除会打开草稿编辑窗口，不会立即撤权。

编辑窗口提供「成员 / 添加成员 / 仅看变更」三个视图，底部固定显示待添加、待移除人数。在变更视图中可选中人员撤销单项或多项修改。关闭时点击「取消」丢弃整个草稿。

「预览影响」先读取授权组最新数据，将本次明确添加、移除的成员应用到最新成员集合，保留其他管理员的调整。提交仍使用最新版本和预览令牌；预览后数据变化会要求重新预览。

权限预览按用户汇总，可搜索并展开受影响节点，每页最多显示 50 位用户。移除成员时会分别说明移除人数和实际失去节点权限的人数。mTLS 绑定按用户分组，可筛选待处理人员，并继续使用每位用户自己的证书。

## 升级现有授权

升级时，拥有完全相同节点集合的用户自动合并到同一个「迁移授权组 N」。没有节点的用户不自动入组。原连接密码、证书绑定、订阅令牌和流量数据保留。

迁移组可改名并重新整理。注意：迁移后修改组的节点会影响组内所有成员。

升级后的服务只允许通过组修改节点权限；旧客户端的个人节点分配和移除操作会被拒绝，需要升级客户端。新版客户端连接旧服务时仍可使用原有个人分配流程。
